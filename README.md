## Audio & Music

- [Audacity](https://github.com/audacity/audacity) - Audio editor and recorder. `GPL-3.0`
- [Cider](https://github.com/ciderapp/Cider) - Apple Music client built with Vue.js and Electron.
- [Equalizer APO](https://github.com/jaakkopasanen/AutoEq) - System-wide parametric equalizer for Windows.
- [foobar2000](https://www.foobar2000.org/) - Advanced audio player with customizable UI and plugin system.
- [MusicBee](https://getmusicbee.com/) - Music manager and player with auto-tagging and sync.

## Backup & Sync

- [Duplicati](https://github.com/duplicati/duplicati) - Encrypted backups to cloud storage. Supports S3, Backblaze, Google Drive. `LGPL-2.1`
- [FreeFileSync](https://freefilesync.org/) - Folder comparison and synchronization with real-time monitoring.
- [restic](https://github.com/restic/restic) - Fast, encrypted backup program with deduplication. `BSD-2-Clause`
- [Syncthing](https://github.com/syncthing/syncthing) - Continuous file sync between devices. No cloud, no accounts. `MPL-2.0`

## Browsers

- [Brave](https://brave.com/) - Chromium browser with built-in ad blocking and tracker prevention.
- [Firefox](https://www.mozilla.org/firefox/) - Independent browser with strong privacy defaults. `MPL-2.0`
- [Tor Browser](https://www.torproject.org/) - Routes traffic through the Tor network for anonymous browsing.
- [Vivaldi](https://vivaldi.com/) - Chromium browser with tab stacking, tiling, and deep customization.
- [Zen Browser](https://github.com/nicoth-in/zen-browser-alpha) - Firefox-based browser focused on minimal design.

## Contributing

Know a rad Windows app that's missing? Open a PR.

**Rules:**

1. One app per pull request.
2. Use the format: `[Name](link) - Description. \`License\``
3. Description should be one sentence that tells people what the app does. No marketing.
4. Add it in alphabetical order within its category.
5. Open-source apps should include a license tag.
6. The app needs to actually work on Windows. Cross-platform is fine.
7. No abandoned projects. Last commit within the past 2 years.

Not sure if something belongs? Open an issue and ask. No stupid questions.
